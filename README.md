# CopyChat

A Darktide Mod Framework mod that copies recent chat and system messages to the clipboard, with configurable time and message limits and optional player-name anonymization.

## Installation

Install DMF, place the `CopyChat` folder in Darktide's mods directory, and add `CopyChat` to `mod_load_order.txt`.

## Download

Download `CopyChat.zip` from the [latest GitHub release](../../releases/latest). Do not use GitHub's source-code archives for installation.
